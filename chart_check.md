# Перевірка діаграми (чек-лист)

Відмічайте кожен пункт для кожної діаграми:

- [ ] Є запитання і аудиторія; діаграма відповідає на це запитання.
- [ ] Тип діаграми відповідає даним (категорії — стовпчики, час — лінія, зв’язок — scatter, розподіл — гістограма/boxplot).
- [ ] Є заголовок із висновком чи темою, підписи осей з одиницями, легенда за потреби.
- [ ] Стовпчики починаються з нуля; масштаб не спотворює різницю.
- [ ] Кольорів небагато, вони розрізняються також за контрастом або маркером; текст читається.
- [ ] Показано невизначеність або обмеження (розмір вибірки, період, викиди).
- [ ] Є короткий текстовий опис діаграми для людей, які її не бачать.
